# Native MERCI saved-score row-order replay

- `complete_score_table_orders.csv`: 80 saved-score row-order replays across four score objects (P2 and three reference pairings from one library of unresolved identity, not four independent patients) in two ranking scopes.
- `P2_neff_fixed_rna_orders.csv`: the ten P2 rows with fixed RNA order displayed in Supplementary Note S12.
- `upstream_replay_verification.json`: verification record for the 800 cutoff predictions executed by the original MERCI predictor without refitting Neff/SVR or reconstructing raw reads.
