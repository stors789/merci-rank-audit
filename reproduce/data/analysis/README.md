# Additional manuscript aggregate tables and eight-cell fixture

- `tables/task_partition_table.csv` and rounded companion `tables/merci_order_indeterminacy_by_task.csv`: 240 original-regular tasks (120 mixed coculture and 120 monoculture/negative tasks across 20 development, 80 frozen batch 1 and 20 retrospective batch 2 technical splits; splits share cells and are not independent patients). `call` is the supplied-order raw DNA-RNA overlap R before the sample gate; `core` is the raw-family intersection across all legal Neff tie orders; `frac_call_not_core` is `(call - core_in_call) / call`; `original_gate` records supplied-order gate passage (44 failed-gate tasks retain positive raw overlaps).
- `tables/reference_summary.csv`: 51-case formal benchmark exact-family and reference summary, including `raw_possible_N = 1108` for the full 3,786-cell monoculture control (`MC_only`).
- `tables/table1_case_summary.csv`: four-row summary corresponding to main Table 1 (`P2`, `MC-only`, `Batch 2 negative`, `GBML181`), mapping each row to `reference_summary.csv` and recording that `MC-only` (core/union 980/1,108) is a single full-cohort run over all 3,786 monoculture cells rather than one of the 120 per-split monoculture tasks (median core 915, range 252-997).
- `eight_cell/`: eight-cell `all_tied_single` fixture and enumeration verification for Supplementary Methods S1.
